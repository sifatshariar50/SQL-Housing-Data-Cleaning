SQL Housing Data Cleaning Project

Project Overview

This project focuses on cleaning and improving the quality of housing sales data using SQL. It demonstrates practical SQL skills for identifying data quality issues, handling missing values, checking duplicates, and standardizing inconsistent records.

Objectives

Explore the housing dataset and understand its structure.

Identify missing values and potential duplicate records.

Investigate missing property addresses using ParcelID relationships.

Standardize inconsistent categorical values.

Validate the data after cleaning.

Run validation queries to check data quality after the cleaning operations.
